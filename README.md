# 🧮 Interactive Abacus Game

An interactive single-page web application that simulates a 5-rod abacus. The game displays a target number and allows users to manipulate beads on an abacus to match the number using place-value logic.

# 🚀 Live Demo

👉 https://abacusassignment.vercel.app

## 🚀 Features

* Randomly generated target number (0–99999)
* 5-rod abacus representing:

  * Ten-Thousands
  * Thousands
  * Hundreds
  * Tens
  * Units
* Add (+) and Remove (-) beads on each rod
* Automatic carry-over when bead count exceeds 9
* Real-time calculation of current abacus value
* Instant feedback if the number matches the target
* New Question button to reset game

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript



## ▶ How to Run

1. Download or clone the project.
2. Open `index.html` in any modern web browser.
3. Start adjusting beads to match the target number.
